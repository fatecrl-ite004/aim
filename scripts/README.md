# Scripts da V1

Os scripts PowerShell preparam o ambiente local, iniciam e param os serviços, executam o replay técnico e verificam o resultado. O percurso recomendado para a apresentação começa pelo botão **Iniciar demonstração** na interface; os scripts `demo-v1.ps1` e `demo-v1-docker.ps1` permanecem disponíveis para reprodução e verificação técnica.

Consulte [deploy.md](../deploy.md) antes de executar. O recorte AIOpsArena e as credenciais ficam fora do repositório; saídas e logs locais são gravados em `.runtime/`, ignorado pelo Git.
