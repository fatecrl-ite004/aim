# Registro de decisões

Esta pasta documenta decisões de arquitetura e pesquisa quando houver uma escolha explícita, responsável, data, alternativas consideradas e evidência. O processo sugerido é registrar contexto, decisão, consequências e critérios de revisão.

**Estado atual:** não há ADR aceita. Métodos candidatos, desenho conceitual e pastas previstas não são decisões. Não criar registro retroativo como se uma escolha tivesse sido aprovada.
