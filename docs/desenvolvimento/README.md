# Desenvolvimento

Espaço para convenções de contribuição e processo de desenvolvimento quando forem definidos. Atualmente não há stack, execução local, pipeline de integração contínua, serviço implantável ou teste de sistema neste repositório. Não interpretar os diretórios vazios como código existente.

Fluxo de trabalho sugerido: documentar hipótese/requisito → definir critérios → validar desenho com responsáveis → experimentar em `research/` quando for pesquisa → registrar resultado e decisão → implementar em `system/` somente após aprovação e escopo técnico definido.

Registro da organização documental: [migração de 28/10/2026](migracao-2026-10-28.md).
