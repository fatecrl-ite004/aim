# Sistema PoC

`system/` é o destino previsto para componentes do produto/PoC, distinto de `research/` (código de investigação) e `docs/` (documentação). Frontend, backend e inferência ainda não foram implementados; esta árvore não indica serviços implantáveis nem arquitetura de processos aprovada.

Uma decisão futura deve definir se inferência será módulo integrado ou serviço independente, com evidência de requisitos de latência, escala, operação e fronteiras de dados. Não há linguagem ou framework escolhido.
